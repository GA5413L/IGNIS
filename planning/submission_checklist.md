# Submission checklist (to complete during the event; nothing here is done yet)

## Eligibility
- [ ] All team members registered; team ≤ 6; one challenge; Local Event chosen (Universal Event teams need ≥ 2 members)
- [ ] Organizer ruling on pre-event research recorded (U1/U2), and the submission is consistent with it
- [ ] `CHRONOLOGY.md` updated: what existed before 14 Nov 09:00, and what was made during the event
- [ ] Submitted via the team's Project tab before the Local Event deadline (window closes Sun 15 Nov 23:59 local per the 2026 home page; check your Local Event)
- [ ] Re-read the **Project Submission Guide** and the **Judging & Awards Guide** (published 13 Nov) and update this list

## Content
- [ ] Opening screen shows one meaningful scientific result with the actual NASA evidence
- [ ] At least one consequential distinction or limitation is visible without digging
- [ ] More than one genuine supported query works live (e.g. B4 and B12 within-burn; the N1 gravity case)
- [ ] Dossier export works, and its numbers match the UI exactly
- [ ] No safe/unsafe labels, no confidence percentages, no continuous gravity slider, no prediction
- [ ] No claim of NASA affiliation or endorsement

## Required statements
- [ ] **SI-usage description** (mandatory per the FAQ): which tools, for what, and what humans checked
- [ ] **Every source cited** (T&C), including Link et al. 2018 + ESM, NASA/TM-20210011385, and any library or tool
- [ ] Licences for all third-party materials identified (T&C); original content OSI-licensed (Apache-2.0 default)
- [ ] No figures or images reproduced from Elsevier papers; Link et al. figures only under CC BY 4.0 with attribution and change notes; NASA images per NASA media guidelines
- [ ] Evaluation results reported honestly, including where IGNIS was not better than the spreadsheet baseline

## Technical
- [ ] Transcription check 6/6 PASS on freshly downloaded PDFs (output saved)
- [ ] Unit tests for every failure mode in `implementation_blueprint.md` §6, with actual results saved
- [ ] App runs without any API key
