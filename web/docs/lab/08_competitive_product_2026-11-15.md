# Current competitor product/source comparison — 15 November 2026

**Finding:** IGNIS has a useful, implemented specialty, but neither an integrated research workflow nor source provenance is unique. VESTA already has evidence receipts with rechecking and a static API/MCP path. ZERO FLARE has the broadest reviewed investigation-to-calculator-to-saved-work flow. IGNIS's defensible contribution in this set is its particular combination of workbook-cell detector analysis, explicitly unresolved source-version conflicts, separate condition-coordinate gaps, and quantity-aware claim revision. This is a bounded source comparison, not measured scientific or product superiority.

### VESTA: a substantial reproducibility and public-reuse competitor

The evidence-room component actually wires search, cabin configuration, comparison, gap briefs and receipt controls; applying a rechecked receipt updates the cabin state. This is implemented navigation, not a list of aspirational features. The source drawer renders context around quotations and a row/column/raw-cell table. Its verification badge means cached-text or cell matching, not validation of the interpretation. [Evidence-room wiring](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/web/js/world/act-evidence.js#L187-L215), [source drawer](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/web/js/ui/drawer.js#L50-L98)

Receipts bind explicit-unit queries, matching rules, dataset fingerprints, coverage results and referenced row snapshots. Rechecking distinguishes method, evidence-base and result changes; strict parsing rejects unsupported or oversized payloads. Tests cover altered rows, removed evidence, policy changes and missing coordinates. These tests were inspected, not rerun. Research-gap briefs separately rank unanswered or extrapolated questions under a disclosed heuristic and export Markdown/JSON. [Receipt implementation](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/web/js/core/receipt.js#L34-L121), [receipt tests](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/tests/core/receipt.test.mjs#L12-L117), [gap-brief policy](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/web/js/core/gapbrief.js#L25-L94)

Coverage uses same-row oxygen, pressure and gravity, with oxygen tolerance 1 percentage point and pressure tolerance 5 kPa; inferred pressure is flagged. Flow, geometry, thickness and ignition are outside that match. This is stronger than independently covering each axis, but still does not establish physical equivalence. The runtime search/coverage/drill is deterministic; SI assisted authorship is disclosed. A four-tool MCP server uses the same core, while the new robotics station is explicitly scripted and human-approved. [Matching rule](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/web/js/core/match.js#L1-L17), [declared scope](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/web/js/core/receipt.js#L8-L15), [MCP tools](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/mcp/server.mjs#L99-L164), [robotics boundary](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/web/js/world/act-robotics.js#L5-L90)

Its generated metadata declares 24 investigations, 22 tables, 1,989 source records and 822 findings. These are different units, not independent experiments or independently validated conclusions. Source-level reuse is particularly credible because explicit code licensing accompanies the static API and source exports. [Generated metadata](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/web/data/meta.json), [code and third-party terms](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/LICENSE#L4-L34)

### ZERO FLARE: breadth, analytical exploration and saved research

The page renders investigations, comparison, scenarios, research tools and My Work. Investigation charts calculate distributions, paired scatter/correlation, categorical summaries, row-order trends and completeness from recovered rows, with filename/hash context. My Work exports saved items, gaps, sessions, notes, provenance and limitations. This is a serious alternative for a researcher exploring many studies before choosing a narrow question. The inspected investigation registry contains 25 records: **24 Combustion Science plus one Fluid Physics** record; the catalog returns that collection. [Actual page routes](https://github.com/yousufaways-23/zero-flare-lab/blob/28f105cc4220cac8b7782dd6d229d5fff33e1c76/src/app/page.tsx#L22-L84), [chart composition](https://github.com/yousufaways-23/zero-flare-lab/blob/28f105cc4220cac8b7782dd6d229d5fff33e1c76/src/components/flame/investigations/ExperimentCharts.tsx#L332-L350), [packet export](https://github.com/yousufaways-23/zero-flare-lab/blob/28f105cc4220cac8b7782dd6d229d5fff33e1c76/src/components/flame/mywork/MyWorkView.tsx#L39-L86), [catalog](https://github.com/yousufaways-23/zero-flare-lab/blob/28f105cc4220cac8b7782dd6d229d5fff33e1c76/src/lib/data/catalog.ts#L77-L97)

Its comparison gate identifies gravity, scale, hardware and outcome mismatches. Some gravity/scale classifications come from metadata heuristics, so the gate is not a complete measurement-operator contract. The model registry contains 11 models and six environments, distinguishing eight implemented entries from three documented-only ones. Those lifecycle labels are the authors' classifications. The FLEX branch returns an explicitly uncalibrated relative score and refuses inputs rejected by its applicability guard. Published model-card validation metrics and acceptance-test counts were not reproduced here. [Comparability implementation](https://github.com/yousufaways-23/zero-flare-lab/blob/28f105cc4220cac8b7782dd6d229d5fff33e1c76/src/lib/science/comparability.ts#L33-L150), [model registry](https://github.com/yousufaways-23/zero-flare-lab/blob/28f105cc4220cac8b7782dd6d229d5fff33e1c76/src/data/generated/mathematical_models.json), [FLEX output semantics](https://github.com/yousufaways-23/zero-flare-lab/blob/28f105cc4220cac8b7782dd6d229d5fff33e1c76/src/lib/science/math-models.ts#L279-L297)

### SPICA: coherent condition story, with a consequential joint-coverage limit

SPICA's evidence modal shows ranges, plotted rows, nearest oxygen and pressure records, outcomes and DOI links. It includes beyond-PSI literature separately from its bundled coverage arithmetic, and can print a mission brief. Its current data loader deliberately removed a stale cross-origin fallback and uses current bundled data if the intended API is unavailable. These are useful source and deployment distinctions. The 2,012 bundled records comprise 1,885 per-test, 119 day-aggregate and eight design-range records; the total is not a count of independent burns. ## What IGNIS can positively demonstrate, and what remains open

1. **Follow a detector statistic to its actual stored cells.** Select Kapton / ISS scatter / 2 V: 20 of 35 finite readings below the descriptive cutoff, 36 total rows, AW50 missing. Teflon gives 18/23. Inspect four channels, DBP references, original values/formulas and the unresolved CSV/workbook identity mismatch. The cutoff is analyst-selected, not a spacecraft alarm threshold; repeated/aged records are not declared independent replicates. The reviewed VESTA and ZERO SAME-R artifacts have 109 condition rows and no detector voltage columns, while VESTA's outcome field is empty throughout that file. This narrowly supports IGNIS's added workbook analysis, not a universal originality claim. [VESTA SAME-R artifact](https://github.com/itzjk/vesta/blob/e0245b7094dbeda26cc6c8e2b9187c267a28a176/web/api/v1/tests/PSI-101.csv), [ZERO SAME-R artifact](https://github.com/yousufaways-23/zero-flare-lab/blob/28f105cc4220cac8b7782dd6d229d5fff33e1c76/src/data/generated/tables-second/PSI-101_SAME-R.json), [IGNIS provenance](../DETECTOR_DATA_PROVENANCE.md)
2. **Keep a source disagreement visible while comparing conditions.** IGNIS's seven-case Saffire view preserves the 2026 opposed-flow statement and the 2024 concurrent-flow statement for the five overlapping cases, excludes the unresolved flow field from its comparison, and keeps oxygen/pressure gaps separate. It shows how source-version handling changes the claim permitted by the interface. It does not establish a new combustion frontier or spacecraft suitability. [Current conditions implementation](../../src/components/Conditions.tsx)
3. **Revise an overbroad interpretation into a scoped, exportable claim.** The current briefs connect source inspection to W1 conditional model comparison, W2 normalization limits and W3 incompatible heat quantities. Useful answers include a bounded comparison, an unsupported-quantity conclusion and an explicit data requirement. None requires live AI to fabricate missing evidence. [Current build and remaining research limits](../BUILD_STATUS.md)

The nearest product improvements are correspondingly concrete: add receipt import/recomputation with changed-source/method/result states, taking VESTA and MORS as existing benchmarks; add persistent saved selections/questions if longer research sessions become a priority, taking ZERO/MORS as benchmarks; then test the three tasks above against equally informed source tables with blinded error/time scoring. Those are future evaluations, not completed benefits. They would falsify a usability advantage if source-reading users perform as accurately and quickly, and would expose any loss of provenance during export/replay.

VESTA has an explicit repository license. No `LICENSE`/`LICENCE`-named file was found in the complete pinned ZERO, SPICA or MORS trees; that is a filename-inventory finding, not a legal conclusion about every file. IGNIS also has an unresolved original-code license and an intentional release hold. Public access, documented reuse rights, source integrity and adoption by a research organization are separate milestones. This review supports reusable artifacts and a precise demonstration; it does not support SOTA, NASA adoption, live-AI superiority or a competition outcome claim.
