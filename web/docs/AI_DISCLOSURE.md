# AI assistance and preparation disclosure

IGNIS was developed by team Emberfall with assistance from **OpenAI Codex** and **Claude Code**, including Claude helper/model reviews. The product label **SI** means Scientific Intelligence; development assistance remains AI assistance.

## Development use

AI tools assisted literature discovery, source reading, research synthesis, software design, coding, debugging, test preparation, interface integration, figure code and presentation text. The teammate's interface was integrated with the research backend. Helper reviews contributed to scientific-contract and implementation checks; they were not independent human scientific reviews.

Data curation, selection rules, paraphrased findings and model-applicability prose were also AI-assisted. NASA measurements remain attributed to their original sources and are not described as AI-generated experiments. Review fields retain `assistant_checked`; no record is promoted to independent human review by software tests or this documentation cleanup.

Source checks used acquired file hashes, publication text and table inspection, original spreadsheet cells, units, missing/error states and deterministic curation scripts. [Atlas provenance](ATLAS_DATA_PROVENANCE.md), [detector provenance](DETECTOR_DATA_PROVENANCE.md) and the scientific-method documents preserve the relevant source identities and limitations.

Charts and interface artwork were created in code with AI assistance. Plots use the curated source values; the flame artwork is illustrative. No NASA logo, mission insignia or generated photographic evidence is presented as a research observation.

## Runtime behaviour

The current floating SI panel searches reviewed catalogue findings by keyword. Scientific calculations and assessments use the deterministic application core. No runtime configuration has passed the required acceptance process, so live model interpretation remains disabled.

The prepared Cloudflare integration is limited to interpreting an acknowledged public question into a proposed scope, followed by explicit confirmation and a source-bound assessment. Uploaded CSVs and notebooks are not automatically attached. Actual provider experiments, interpretation errors, incomplete runs and usage are recorded in [SI preparation](SI_PREPARATION.md); connection tests and mocks are not semantic acceptance.

The project does not claim independent human scientific validation, predictive superiority, NASA endorsement/adoption or a completed researcher-benefit study. Removing internal planning files after submission does not remove this disclosure or alter the original development history.
