# Floating SI chat

The console now offers an **Ask SI** launcher at the lower-right corner of every view. At the owner's follow-up request, the dedicated SI page, form and navigation item have been removed. Old `#si` bookmarks lead to the overview. The chat links to Sources and the notebook; model claim checks remain in Findings.

The panel supports quick combustion topics, Enter to send, Shift+Enter for a new line, Escape to close with focus restored, mobile sizing and conversation retention while navigating the console. Catalogue mode shows up to three keyword-matched findings from the existing core-generated brief, with original source links and claim qualifications. It retains the twelve latest searches in browser memory only. These are catalogue matches, not generated answers or a scientific interpretation of the question; a missing match is not negative evidence.

When an accepted provider is configured, the same panel uses the existing public-only consent, Turnstile, authenticated interpretation receipts, scope confirmation and source-bound assessment exports. Uploaded CSVs and notebook contents are not attached to provider questions. Acceptance and deployment settings were not changed, and no provider inference was performed for this UI change.

The teammate can deploy the ordinary Next.js build after pulling the latest source. No added dependency or environment variable is required for the chat interface or catalogue search.
